## Featured projects

### Automated tourism data pipeline
End-to-end collection, transformation and storage pipeline, from scraping to interactive maps.
Originally designed for a cloud infrastructure, it was rebuilt locally around an S3-compatible
data lake and a relational warehouse, with environment-driven configuration to stay portable.
Ran end to end over 35 cities and 105 hotels, producing 4 datasets and 2 interactive maps.

`Python` `Docker` `MinIO` `PostgreSQL` `boto3` `SQLAlchemy`
[Source code](https://github.com/AichaFa/2-Projets-Fullstack/tree/main/1-Construire%20et%20g%C3%A9rer%20une%20infrastructure%20de%20donn%C3%A9es/Projet-Planifiez%20votre%20voyage%20avec%20Kayak)

### Rental pricing optimisation and delay analysis
Full machine learning lifecycle: exploratory analysis, training, experiment tracking, API
exposure and web interface. Answers two business questions for a car-sharing platform:
what minimum delay to enforce between two rentals, and what price to recommend per vehicle.

`Python` `scikit-learn` `MLflow` `FastAPI` `Streamlit` `Docker`
[Source code](https://github.com/AichaFa/2-Projets-Fullstack/tree/main/5-Deploiement/getaround_project) · [Live demo](https://huggingface.co/AichaFaHugFace)

### Medical consistency audit
Multimodal AI project detecting inconsistencies between a chest X-ray and its radiology report.
Two approaches compared: cross-attention between visual and textual representations, and
similarity between embeddings from contrastive pre-training.

`Python` `PyTorch` `Transformers` `LoRA` `MLflow`
[Source code](https://github.com/AichaFa/2-Projets-Fullstack/tree/main/6-Diriger%20un%20projet%20de%20donn%C3%A9es/Auditeur_Coherence_Medicale)

All projects are available in the
[2-Projets-Fullstack](https://github.com/AichaFa/2-Projets-Fullstack) repository.
