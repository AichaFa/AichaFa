# 🎓 Formation Data Fullstack - Jedha Bootcamp

Ce dépôt contient l'ensemble de mes travaux, exercices et projets réalisés durant ma formation **Data Fullstack** chez Jedha.

## 🗂️ Structure du Repo

Le projet est organisé en deux grandes phases :

### 1. Data Essentials 🟢
*Bases de la Data, analyse exploratoire et outils fondamentaux.*
* **Dossiers :** Python, Pandas, SQL, Visualisation de données.

### 2. Data Fullstack 🔵
*Approfondissement technique et mise en production.*
* **Dossiers :** Collecte de données (APIs, Scraping avec Scrapy), Programmation asynchrone, Gestion de bases de données avancées.

---

## 🛠️ Technologies utilisées
* **Langages :** Python 🐍, SQL
* **Bibliothèques :** Pandas, BeautifulSoup, Scrapy, Asyncio
* **Outils :** Jupyter Notebooks, Git/GitHub
